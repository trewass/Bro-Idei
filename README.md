# Fear-Killer - Приложение для преодоления страхов

Fear-Killer - это мобильное приложение на React Native/Expo для работы со страхами и фобиями. Приложение позволяет создавать карточки страхов, записывать аудио-заметки и отслеживать прогресс.

## Требования к системе

- Node.js 18.0 или выше
- npm 9.0 или выше (или yarn)
- Expo CLI
- Для iOS: macOS с установленным Xcode
- Для Android: Android Studio с настроенным эмулятором

## Структура проекта

```
├── types/                 # Дополнительные типы

├── babel.config.js        # Конфигурация Babel
└── app.json              # Конфигурация Expo
```

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd Fear-Killer
```

### 2. Установка зависимостей

```bash
npm install
# или
yarn install
```

### 3. Запуск приложения

#### Запуск в режиме разработки:

```bash
npm start
# или
expo start
```

#### Запуск на конкретной платформе:

```bash
# iOS (требуется macOS)
npm run ios

# Android
npm run android

# Web
npm run web
```

### 4. Использование Expo Go

1. Установите приложение Expo Go на свой телефон из App Store или Google Play
2. Запустите проект командой `npm start`
3. Отсканируйте QR-код из терминала с помощью:
   - iOS: камера телефона
   - Android: приложение Expo Go

## Основные функции

### 1. Карточки страхов
- Создание карточек с описанием страхов
- Добавление тегов для категоризации
- Отслеживание прогресса работы со страхом
- Архивирование завершенных карточек

### 2. Аудиозаписи
- Запись голосовых заметок о страхах
- Сохранение аудио локально на устройстве
- Воспроизведение записей
- Транскрибирование аудио (заглушка для будущей интеграции)

### 3. Темы оформления
- Светлая и темная темы
- Автоматическое переключение по системным настройкам

### 4. Локальное хранилище
- SQLite база данных для хранения карточек
- Безопасное хранилище для чувствительных данных
- Офлайн-доступ ко всем данным

## Решение проблем

### Ошибки TypeScript

Если возникают ошибки TypeScript после установки зависимостей:

```bash
# Очистите кэш TypeScript
rm -rf node_modules/.cache
rm tsconfig.tsbuildinfo

# Переустановите зависимости
rm -rf node_modules
npm install
```

### Ошибки Metro bundler

```bash
# Очистите кэш Metro
npx expo start --clear
```

### Проблемы с iOS

```bash
# Если используете нативные модули
cd ios
pod install
cd ..
```

## Разработка

### Добавление новых компонентов

Компоненты размещаются в `Fear-Killer/components/`. Используйте TypeScript и React Native Paper для UI.

### Работа с базой данных

База данных инициализируется автоматически при первом запуске. Схема находится в `Fear-Killer/services/database.ts`.

### Стилизация

Приложение использует React Native Paper для компонентов UI. Цветовая схема определена в `Fear-Killer/utils/theme.ts`.
